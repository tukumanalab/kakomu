# kakomu

**[青学つくまなラボ](https://sites.google.com/view/tukumanalab/)のための、アクリルスタンド／アクリルキーホルダー制作ツール。**

好きな絵や写真を置き、それを囲む線をつくり、レーザー加工機と UV プリンターに渡します。Windows / macOS / Linux（omarchy を含む）で動きます。

- サイト: https://tukumanalab.github.io/kakomu/
- 設計仕様: [SPEC.md](SPEC.md)

> **状態: 設計中。** 現在このリポジトリにあるのは仕様と Web サイトのみで、アプリの実装はまだ始まっていません。

## なにをするツールか

つくまなラボでは今 Inkscape を使っています。Inkscape は強力な汎用ドローツールですが、この作業をするには「ビットマップのトレース」「アウトセット」「ノード編集」を順に使う必要があり、設定項目も専門用語も多い。初等部の子に渡せる導線ではありません。

kakomu は Inkscape を置き換えるものではなく、**そこにあるワークフローのうちこの 1 つだけ**を取り出して、初等部の子から教職員までが使えるように作り直したものです。

```
1. 絵を入れる
2. 「うしろを消す」    … ローカル AI モデル。画像を外部に送信しない
3. 「囲む」            … 絵の 3mm 外側に、切るための線ができる
4. 点をドラッグして形を整える
5. 部品をつける        … キーホルダーなら φ4mm の穴、アクスタなら台座
6. 「かきだす」        … 切るデータ .svg ＋ 刷るデータ .pdf
```

### 成功条件

> 初等部の子が、スタッフの短い声かけだけで、1 回の来室（13:00〜18:00 のうち）にアクリルキーホルダーを 1 つ完成させられること。

これが唯一の成功条件です。上級者向けの機能は、この条件を壊さない範囲で足します。

## 設計の柱

| | |
|---|---|
| **1 つの画面で、小 1 から教職員まで** | 子ども用の画面を別に作りません。ボタンの位置も機能も同じまま、**かんじ／ふりがな／ひらがな**を切り替えます。「世代の壁を取り払う」という施設の掲げ方に沿うため |
| **座標系はすべて mm** | UI にピクセルを出しません（例外は実効解像度の dpi 表示のみ）。加工機に渡すデータで最も事故が起きるのが単位系です |
| **切れない形を作らせない** | 最小幅 1.5mm・最小穴径 φ2mm・自己交差・鋭角を自動チェックし、**なぜダメかとどう直すか**をセットで出します。エラーは門番ではなく教材です |
| **破壊的な操作を作らない** | 背景も切る線も元データを消さず、元画像は `.kkm` 内に無改変で残ります。戻れると分かっていれば試行錯誤できます |
| **オフラインで完結** | AI 推論はすべてローカル。未成年が使うため、画像を外部に送信しません |

## 用語について

このリポジトリでは **「入稿」という言葉を使いません**。入稿は外部の印刷業者にデータを渡す行為を指す言葉で、加工機が同じ部屋にあるファブスペースの体験とずれるためです。

| 使わない | 使う |
|---|---|
| 入稿データ | 加工データ／切るデータ・刷るデータ |
| 入稿する | 加工機に渡す／出力する |
| 業者 | ラボ／加工機 |

UI に出す言葉はさらに噛み砕きます。対応表は [SPEC.md の 3.4](SPEC.md#34-用語の対応表) を参照してください。

## 技術スタック

- **アプリシェル**: Tauri v2
- **フロントエンド**: TypeScript + Solid.js（キャンバスは SVG DOM）
- **コア**: Rust — `kurbo` / `clipper2`（ジオメトリ）、`ort`（ONNX 推論）、`printpdf`（PDF 生成）
- **同梱**: 背景除去モデル（`u2netp`）、UD フォント（BIZ UDGothic / Zen Maru Gothic）
- **配布**: MSI / NSIS・dmg（Universal）・AppImage・AUR

詳細と選定理由は [SPEC.md](SPEC.md) を参照してください。

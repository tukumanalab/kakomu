# kakomu

**アクリルスタンド／アクリルキーホルダーの入稿データを作るための、用途を絞ったベクターエディタ。**

画像を配置し、その周囲を囲むカットラインを自動生成し、カットラインは SVG、絵柄は UV プリンタ向けの PDF として書き出します。Windows / macOS / Linux（omarchy を含む）で動作します。

- Web サイト: https://tukumanalab.github.io/kakomu/
- 設計仕様: [SPEC.md](SPEC.md)

> **状態: 設計中。** 現在このリポジトリにあるのは仕様と Web サイトのみで、アプリの実装はまだ始まっていません。

## なぜ作るか

このワークフローは今のところ複数のツールをまたぐ必要があります。

```
Photoshop / rembg で切り抜き  →  Illustrator / Inkscape でパス化  →  手作業で 3mm オフセット
```

kakomu はこれを 1 本の導線にまとめます。

```
1. 画像をインポート
2. 「背景を消す」        … ローカル AI モデル。画像を外部に送信しない
3. 「カットラインを作る」  … アルファ形状の 3mm 外側にベジェ曲線を生成
4. ノードを数点ドラッグして形を整える
5. アクキーなら ø4mm の穴、アクスタなら差し込みスリット付きの台座を追加
6. 書き出し             … カットライン .svg ＋ 絵柄 .pdf
```

## 設計の柱

| | |
|---|---|
| **座標系はすべて mm** | UI にピクセルを出しません（例外は実効解像度の dpi 表示のみ）。印刷用ツールで最も事故が起きるのが単位系です |
| **破壊的な操作を作らない** | 背景透過もカットライン生成も元データを消さず、元画像は `.kkm` 内に無改変で保持されます |
| **加工可能な形状を出す** | 生成後に最小幅 1.5mm・最小穴径 ø2mm・自己交差・鋭角を自動チェックし、問題箇所をキャンバス上に表示します |
| **オフラインで完結** | AI 推論はすべてローカル。ネットワークはモデルの初回ダウンロードと更新確認のみ |

## 技術スタック

- **アプリシェル**: Tauri v2
- **フロントエンド**: TypeScript + Solid.js（キャンバスは SVG DOM）
- **コア**: Rust — `kurbo` / `clipper2`（ジオメトリ）、`ort`（ONNX 推論）、`printpdf`（PDF 生成）
- **配布**: MSI / NSIS・dmg（Universal）・AppImage・AUR

詳細と選定理由は [SPEC.md](SPEC.md) を参照してください。

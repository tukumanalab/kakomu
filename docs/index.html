kakomu

/kakomɯ/ — 囲む。絵を囲む線をつくる。

すきな絵を、アクリルのキーホルダーにする。

絵を入れて、うしろを消して、まわりを囲む線をつくります。あとはレーザー加工機と UV プリンターに渡すだけ。

GitHub せつめい SPEC.md

つくりかた

はじめてでも、その日のうちに 1 こできる。

1 回で 1 こ作りおわることを目指して設計しています。とちゅうで別のソフトに移りません。

  1. 絵を入れる。写真でもイラストでも、画面にドラッグするだけ。
  2. うしろを消す。ボタンを 1 回おすと、背景が自動で消えます。インターネットに送りません。
  3. 囲む。絵の 3 ミリ外がわに、切るための線ができます。
  4. かたちを整える。線の上の点をドラッグして、細すぎるところを太くします。
  5. 部品をつける。キーホルダーなら穴、立てるなら台座。大きさは決めてあります。
  6. かきだす。切るデータと印刷するデータが、いっしょに出てきます。

よみやすさ

同じ画面のまま、文字だけ変わる。

使う人は小学校 1 年生から先生までいます。だから子ども用の画面を別に作りません。画面の作りはそのままで、かんじとひらがなを切りかえます。このページの右上でもためせます。

±変わるもの

  • 文言 — 言いかえた別のことばに差しかわる
  • 書体 — 丸ゴシックになる。教科書に近い字のかたち
  • 文字の大きさ — 1.15 倍になる
  • 行のあいだ — 広がって読みやすくなる
  • 単位 — 「3mm」が「3ミリ」になる

=変わらないもの

  • ボタンの位置 — どこに何があるかは同じ
  • できること — 機能をへらしません
  • 作ったデータ — 出てくる SVG と PDF は同じ
  • となりの人と話せる — 画面が同じなので、教える人と見ている画面がずれない

ふりがなではなく、言いかえにした理由

「背景」に「はいけい」とふりがなを振っても、意味は分かりません。読めることと分かることは別です。だから人が言いかえを書き下ろします。機械での自動変換はしません。

ふりがなモードも作りません。ルビは行のあいだを大きく崩すので、レイアウトが 2 段階で変わることになります。読めないなら、ふりがなを足すよりことばごと変えた方が確実です。

ひらがなを書くときの決まり

  1. 分かち書きにする。教科書に合わせて、ことばのくぎりでスペースを空けます。「きるせんを つくる」
  2. 1 文を 20 文字までにする。長い文は読むのをやめてしまいます。
  3. カタカナは意味が伝わるものだけ。「アクリル」「データ」は残します。「オフセット」「レイヤー」は使いません。
  4. 単位はカタカナで書く。「3mm」ではなく「3ミリ」。
  5. 打ち消しの言い方をさける。「保存されていません」ではなく「まだ ほぞんして いません」。

切りかえは画面の右上にいつも置いてあり、設定の奥にはしまいません。1 回おすだけで変わり、次に開いたときも覚えています。書体は Windows の UD デジタル教科書体などを使いますが、Mac と Linux には入っていないのでソフトにいっしょに入れて配ります。どのパソコンでも同じ読みやすさになるようにするためです。

これまでとの ちがい

Inkscape でやっていたことを、みんなが使えるかたちに。

今は Inkscape を使っています。とても強いソフトですが、この作業をするには手数が多く、言葉もむずかしい。小さい子には渡しにくい道具です。

Inkscape でつくるとき

1画像を読みこむ
2背景を消す（べつのソフトがいる）
3「ビットマップのトレース」でパスにする
4「アウトセット」を何回かおして太らせる
5ノードを編集してかたちを直す
6穴と台座を自分で描く（大きさを調べる）
7SVG で保存、PDF で書き出し（べつべつに設定）

専門の言葉が多い ／ 長さの単位がややこしい ／ 大きさは自分で調べる

kakomu でつくるとき

1絵を入れる
2「うしろを けす」をおす
3「かこむ」をおす（3 ミリ）
4点をうごかして整える
5穴や台座をえらぶ（大きさは入っている）
6「かきだす」をおす（2 つ同時）
  

ひらがなでも使える ／ 長さはぜんぶミリ ／ 大きさは入っている

Inkscape はとても強力なソフトです。kakomu はその代わりではなく、そこにある作りかたのうちこの 1 つだけを取り出して、小学生から先生までが使えるように作り直したものです。

できるデータ

切る機械と、印刷する機械に、そのまま渡せる。

どこかに送るのではなく、同じ部屋にある機械に持っていきます。書き出したあとに、どっちをどの機械に渡すかも画面に出ます。

SVG
きる データ
→ レーザー加工機へ
  • 長さはぜんぶミリ。開くソフトが変わっても大きさが変わりません
  • 線はカットライン用の細さと色（マゼンタ）
  • 穴や台座のスリットも同じデータに入ります
PDF
いんさつする データ
→ UV プリンターへ
  • 原寸のまま、600dpi のこまかさ
  • うしろを消した透明なところは、透明のまま残ります
  • ふちの余白（3 ミリ）も入っています

きれるか しらべる

切れない形は、切る前に教えます。

細すぎるところは折れます。小さすぎる穴は開きません。失敗したアクリル板はもどってこないので、切る前に気づけることを大事にしています。だめな理由と、どう直すかを必ずいっしょに出します。

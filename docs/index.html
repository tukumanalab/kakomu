kakomu

/kakomɯ/ — 囲む。画像を囲むカットラインを作る。

アクスタとアクキーの入稿データだけを作るエディタ。

画像を置き、背景を消し、その 3mm 外側を囲むベジェ曲線を生成する。 カットラインは SVG、絵柄は UV プリンタ向けの PDF で書き出せます。

GitHub で見る → 設計仕様 SPEC.md

なぜ作るか

3 つのツールをまたいでいた作業を、1 本の導線にまとめる。

アクリルグッズの入稿データ作りは、切り抜き・パス化・オフセットがそれぞれ別のソフトの仕事になっています。 kakomu はこの一連だけを引き受けます。汎用ドローイングツールにはしません。

つかいかた

初回でも、5 分で入稿データになる。

これがこのソフトの唯一の成功条件です。チュートリアルなしで通せることを目標にしています。

  1. 画像をインポートする。ドラッグ & ドロップ、またはクリップボードから貼り付け。DPI から実寸を推定して配置します。
  2. 背景を消す。同梱のローカル AI モデルが自動で切り抜きます。画像を外部に送信しません。
  3. カットラインを作る。アルファ形状の 3mm 外側に、なめらかなベジェ曲線が生成されます。
  4. 形を整える。生成結果は普通のパスです。そのままノードツールで細い突起を丸められます。
  5. パーツを足す。アクキーなら ø4mm の穴、アクスタなら差し込みスリット付きの台座。寸法は既定値が入っています。
  6. 書き出す。カットライン .svg と絵柄 .pdf が同時に出力されます。

設計の柱

加工できる形しか出さない。

きれいに見えても、細すぎる突起は折れ、小さすぎる穴は開きません。生成した形は必ず検査します。

Unit

座標系はすべて mm

UI にピクセルを出しません。例外は実効解像度の dpi 表示だけ。印刷用ツールで最も事故が起きるのが単位系だからです。

Check

入稿バリデーション

最小幅 1.5mm、最小穴径 ø2mm、自己交差、開いたパス、内角 20° 未満の鋭角、300dpi 未満の絵柄を自動検査し、キャンバス上に印を出します。

Undo

破壊的な操作を作らない

背景透過もカットライン生成も元データを消しません。元画像は保存ファイルの中に無改変で残ります。いつでも戻れるから試せます。

Local

オフラインで完結

AI 推論はすべて手元で動きます。通信するのはモデルの初回ダウンロードと更新確認だけで、どちらも無効化できます。

書き出し

切る側と刷る側に、それぞれ正しい形式で。

書き出しダイアログは「両方まとめて書き出す」を主導線に置きます。片方を忘れる事故を防ぐためです。

kakomu

アクリルキーホルダーの加工データを作るデスクトップアプリ。

絵を読み込み、背景を消し、その外側に切る線を作り、キーホルダーの穴をあけて、レーザー加工機用の SVG と UV プリンター用の PDF を書き出します。Windows / macOS / Linux で動きます。

ダウンロード GitHub

画面

絵の背景を消して、切る線と穴を作ったところ。

左に道具、中央に板、右に設定・レイヤー・チェック、下に板の大きさ・倍率・絵の解像度が並びます。長さと位置は mm、角度は度で表示します。

使いかた

上のバーのボタンを、左から順に押します。

画面の下に、次にやることが表示されます。

  1. 絵を入れる。画像を選ぶか、窓にドラッグします。PNG / JPEG / WebP / TIFF。板の中央に実寸で置かれます。
  2. 背景を消す。手元の AI モデルで背景を透明にします。画像は外部に送信しません。
  3. 囲む。絵の外側（既定 3mm）に切る線ができ、道具が「点」に切り替わります。
  4. 点を直す。切る線の点やハンドルをドラッグして形を直します。
  5. 穴をあける。切る線の内側のいちばん上に φ4mm の穴が置かれます。「穴」の道具で好きな場所にも置けます。
  6. 書き出す。フォルダを選ぶと、切るデータ（SVG）と印刷するデータ（PDF）が同時に出ます。

機能

それぞれの機能と設定。

数値はすべて v0.2.1 の範囲と既定値です。

絵を入れる・配置する

  • 実寸は画像の解像度情報（PNG の pHYs、JPEG の JFIF）から決め、読めなければ 350dpi とみなします
  • 板（80 × 120mm、変更不可）の中央に置き、はみ出すときは収まるまで縮めます
  • 一辺 16,000px を超える画像は読み込めません
  • ドラッグで移動、四隅で拡縮、上の丸で回転。Shift で軸固定・縦横比維持・15° 刻み
  • X・Y・幅・高さ（mm）と角度（度）を数値で入力できます

背景を消す

  • ONNX モデルを手元で実行します。画像は外部に送信しません
  • 各モデルは初回に 1 回だけダウンロードします（それぞれ約 170MB）
  • 毎回元画像から処理するので、設定を変えてやり直せます。「元に戻す」で消す前に戻り、「消す前と見比べる」で切り替えて表示できます
設定値
絵の種類写真 isnet-general-use（既定）／ イラスト isnet-anime
ふちを締める0–100%（35%）

切る線（囲む）

  • 選んでいる絵の透明度から作ります。背景を消していなければ元画像の透明度を使います
  • 設定を変えたら、もう一度「囲む」を押して作り直します
  • 幅 1.5mm 未満のところは自動で太らせ、直せなければエラーを出します
  • 切る線は 1 本だけで、作り直すと置き換わります。手で直したあとは確認が出ます

※ は「くわしい設定」の中にあります。

点を直す

  • 「点」の道具で、切る線の点を表示します
  • 点をドラッグして形を変えます
  • 点を選ぶとハンドルが出ます。なめらかな点は反対側のハンドルが向きを揃えて動き、角の点は片側だけ動きます
  • 選んだ点は Delete / Backspace で消せます（3 点より少なくはできません）
  • 点の追加と、線を新しく描く機能はまだありません

キーホルダーの穴

  • 「穴をあける」: 切る線の内側で、条件を満たすいちばん上に置きます。押すたびに、ほかの穴を避けて増えます
  • 「穴」の道具: 押した場所にそのまま置きます。置いた穴はドラッグで動かせます
  • 選んだ穴は四隅のハンドルで大きさを変えられます
  • 穴は切る線と同じ色・線幅で SVG に入ります
設定範囲（既定）
穴の大きさφ2–10mm（φ4.0mm）
ふちからの距離1–10mm（3.0mm）

レイヤー・よみかた

  • レイヤーは「部品」「切る線」「絵」の 3 つで固定です。非表示にしたレイヤーは書き出しません
  • 鍵のボタンは表示が切り替わるだけで、いまは編集を止めません
  • 上のバーの「かんじ／ひらがな」で文言を切り替えます。書体・大きさ・配置は変わらず、選択は次回起動時も残ります

書き出し

2 つのファイルを、同じフォルダに同時に書き出します。

ファイル名は最初に読み込んだ画像の名前から付けます。書き出したあと、どちらをどの機械に渡すかを画面に表示します。

SVG
<名前>_切る.svg
→ レーザー加工機 xTool P3（XCS）
  • 切る線と穴。大きさは板と同じ 80 × 120mm、1 単位 = 1mm
  • 線は #FF00FF、線幅 0.1mm、fill="none"
  • 三次ベジェだけで書き、変形は座標に反映済み
  • 切る線も穴も無いときは、板の外形（角 R3mm の角丸長方形）を代わりに書き出します
PDF
<名前>_印刷.pdf
→ UV プリンター Roland BD-8（VersaWorks 7）
  • ページは板に塗り足し 3mm を加えた 86 × 126mm。TrimBox が板の範囲
  • 背景を消した絵はその結果を使い、透明な部分は SMask で残します
  • 600dpi を超える画像は 600dpi に落として埋め込みます
  • 白版は作りません（VersaWorks 側で作ります）

現状

v0.2.1 でできること、まだできないこと。

✓できること

  • 絵の読み込みと配置（移動・拡縮・回転・数値入力）
  • 背景を消す（写真／イラスト）
  • 切る線の自動生成と、点ごとの修正
  • キーホルダーの穴（自動配置・クリックで配置・複数）
  • SVG と PDF の同時書き出し
  • かんじ／ひらがなの切り替え

×まだできないこと

  • 作業の保存と読み込み（アプリを閉じると作業内容は残りません）
  • アクリルスタンドの台座
  • 線を描く・点を足す
  • 板の大きさの変更（80 × 120mm で固定）
  • レイヤーのロック
  • コード署名（初回起動時に OS の警告が出ます）

入れかた

Releases からダウンロードします。

github.com/tukumanalab/kakomu/releases。コード署名をしていないので、どの OS でも初回起動時に警告が出ます。

Windows

.msi ／ -setup.exe

実行して入れます。「WindowsによってPCが保護されました」と出たら、「詳細情報」→「実行」を選びます。

macOS

_universal.dmg（Intel / Apple Silicon）

開いてアプリケーションに入れます。初回は「開発元を確認できないため開けません」と出るので、アプリを右クリックして「開く」を選びます。2 回目からはそのまま開けます。

Linux

.AppImage ／ .deb ／ .rpm

AppImage は実行の許可を付けて起動します。

chmod +x kakomu_*.AppImage ./kakomu_*.AppImage

Arch Linux / Omarchy

AUR には未登録なので、yay -S では入りません。リポジトリの PKGBUILD から入れると、依存パッケージも一緒に入ります。

git clone https://github.com/tukumanalab/kakomu.git cd kakomu/packaging/aur/kakomu-bin makepkg -si

ソースからビルドする場合は packaging/aur/kakomu で同じように makepkg -si します。

AppImage を手で入れる場合は、webkit2gtk-4.1 gtk3 librsvg fuse2 と、ファイルを選ぶダイアログ用の xdg-desktop-portal xdg-desktop-portal-gtk が要ります。-gtk が無いと「絵を入れる」を押しても何も出ません。Hyprland では xdg-desktop-portal-hyprland も入れます。

画面が真っ白になる、描画が崩れるときは、WebKitGTK の DMABUF レンダラを切ります。
WEBKIT_DISABLE_DMABUF_RENDERER=1 ./kakomu_*.AppImage
